# Background photos

Drop `.jpg` / `.png` / `.webp` files here and the card and Reel will use one as
a background, chosen deterministically from the date so a given day always gets
the same image. An empty directory falls back to the built-in gradient.

Images are darkened, blurred slightly and covered with a scrim so the text stays
legible — they are a backdrop, not the subject. Portrait or square crops work
best; the renderer scales-and-crops to fill without distorting.

**Use images you have the rights to.** Photos lifted from a publisher's article
or an unlicensed stock site are a legal problem on a monetized account. Safe
sources include your own photographs, or sites whose licence explicitly permits
commercial use (Unsplash, Pexels) — check the licence for each image.
